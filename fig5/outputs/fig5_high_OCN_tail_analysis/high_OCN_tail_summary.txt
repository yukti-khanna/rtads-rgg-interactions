Required answers:
1. How many unique pairs have OCN >= 40? 93.
2. How does plain F2 perform specifically in this tail? F2: RMSE=0.1431, MAE=0.1063, bias=+0.0157, abs_bias=0.0157, Pearson=0.8623, Spearman=0.8243, R2=0.7396.
3. Does opp_charge_std improve tail RMSE? Yes. F2-P1 minus F2 delta_RMSE=-0.00935; negative means lower RMSE.
4. Does it improve tail MAE? Yes. F2-P1 minus F2 delta_MAE=-0.00623.
5. Does it reduce systematic tail bias? Yes if judged by absolute mean bias: delta_abs_bias=-0.00680.
6. Does the full P8 patch panel improve further? Yes for RMSE/MAE relative to F2 and modestly relative to F2-P1: F2-P8_minus_F2-P1: delta_RMSE=-0.01277, delta_MAE=-0.00942, delta_abs_bias=+0.00261, fraction_improved=0.581, median_abs_error_improvement=+0.00899.
7. What fraction of high-OCN pairs benefit from P1? 0.559.
8. What fraction benefit from P8? 0.591.
9. Does the F2-P1 residual network improve tail RMSE/MAE? No. F2-P1 hybrid_minus_F2-P1: delta_RMSE=-0.00034, delta_MAE=-0.00061, delta_abs_bias=-0.00045, fraction_improved=0.430, median_abs_error_improvement=+0.00000.
10. Does the F2-P8 residual network improve tail RMSE/MAE? Only negligibly. RMSE and MAE both shift slightly in the favorable direction, but the median per-pair improvement is zero and the fraction improved is 0.495. F2-P8 hybrid_minus_F2-P8: delta_RMSE=-0.00038, delta_MAE=-0.00010, delta_abs_bias=-0.00186, fraction_improved=0.495, median_abs_error_improvement=+0.00000.
11. Does either residual network reduce systematic high-OCN bias? F2-P1 hybrid does not; F2-P8 hybrid changes absolute bias by -0.00186, a very small shift.
12. Does either residual network flatten residual-vs-OCN trends? No convincing flattening; slope CIs and trend table should be treated as diagnostic, and the hybrid slopes do not show a robust tail correction pattern.
13. Are tail improvements supported by paired bootstrap confidence intervals? Patch improvements are supported where the relevant RMSE/MAE CIs exclude zero; residual improvements are not supported as a consistent RMSE/MAE/MAE+bias pattern. See tail_bootstrap_differences.csv. Bootstrap RMSE CI excludes zero for P1 vs F2: False; P8 vs F2: True; P8 hybrid vs base: False.
14. Are patch gains concentrated in the high-OCN regime or distributed across OCN values? They are visible in the high-OCN bin summaries and should be read alongside performance_by_OCN_bin.csv/pdf; the main improvement is not a residual-network effect.

16. Based specifically on its intended high-OCN use case, is the residual correction justified? No for F2-P1, and not convincingly for F2-P8.
