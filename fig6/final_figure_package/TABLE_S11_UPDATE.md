# Supplementary Table S11

This is the renamed Supplementary Table S10. Existing experimental sheets are preserved.

The two histidine sheets contain 390 matched pairs. The simulation sheet includes corrected B22 means, within-condition replica SDs, histidine counts and signed pH6.5-minus-pH7 differences. The predictor sheet distinguishes base_prediction (used by the newer supplied audit) from final_hybrid_prediction (used by the existing figure). Both conditions use the same prediction for a given model output and pair. Residuals in this workbook are predicted minus simulated, the opposite of the supplied audit residual convention.

No retraining or new simulations were performed. Raw trajectories, RDF inventories, complete feature tables and charge-proxy analyses are not duplicated. Source hashes are retained in the histidine sheets. The single-command builder now writes Supplementary_Table_S11.xlsx.
